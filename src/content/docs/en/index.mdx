## Before using a machine

- Read the machine's guide in full before using it for the first time.
- Wear the protection listed in the guide: safety glasses, hearing protection, etc.
- Check that the ventilation works before starting a cut or an engraving.
- Never leave a running machine unattended.
- Clean the machine and your workspace after use.
- If in doubt, ask the workshop team for help before starting the machine.

## How the guides work

Every guide follows the same outline, so information is easy to find:

1. **Safety**: the rules to follow before touching the machine.
2. **Hardware reference**: the machine model, its specifications and its manuals.
3. **Materials**: what the machine can work with, and what is not allowed.
4. **Numbered steps**: from switching on to finishing the job, with screenshots.
5. **Cleaning**: how to leave the machine clean for the next person.

The guides are also available in French: use the language picker at the top of the page.
