## Avant d'utiliser une machine

- Lisez le guide de la machine en entier avant votre première utilisation.
- Portez les protections indiquées dans le guide : lunettes, protections auditives, etc.
- Ne laissez jamais une machine en marche sans surveillance.
- Nettoyez la machine et votre poste de travail après chaque utilisation.
- En tout temps, veuillez valider avec le formateur de l'atelier RoboTic avant de démarrer une machine.
